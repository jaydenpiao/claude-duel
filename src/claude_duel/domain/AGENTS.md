# domain

Pure rules. No I/O (`policy._is_submodule` only imports stdlib pure modules to inspect them), no adapters, no logging. Root context: [AGENTS.md](../../../AGENTS.md).

- `vendors.py`: `Vendor`/`VENDORS`, plain metadata for each real vendor (name, model prefix, key env var, default model; ADR 0013). No adapter imports: config and `budget.vendor_of` read it; the container pairs it with `adapters/providers/registry.FACTORIES`.
- `models.py`: `Stage`, `AgentSpec`, `Rules` (`RULES_VERSION` 2, `Rules.dump` omits v2 `heat_token_cap`), `SandboxLimits`, `ChallengeSpec`, `Challenge`, `Validation`, `Attack`, `Usage`, `Event`, `MatchState` (the only mutable aggregate).
- `state_machine.py`: `_ALLOWED` transitions, `next_stage`, `transition`, `recover`.
- `flags.py`: `derive_flag`, `flag_of(secret, cid, epoch)` (repair try `epoch` > 0 derives from `cid~epoch`; `Challenge.flag_epoch` pins the try that built it), `assert_no_flag`, `redact`, `scrub` (the only redactor), `FLAG_PATTERN` (`DUEL{hex}`), `KEY_PATTERNS` + `HEX_PATTERN` = `SECRET_PATTERNS` (backup scans `KEY_PATTERNS` by name), `match_flags(state)` (every epoch's flag; shared by the engine guard and `duel backup`). `assert_no_flag` (and `redact`) also test order-preserving reductions of the text (`_canonical`: hex-only, every other hex char, whitespace-stripped, decimal codes) against every 16-char window of the digest, its reverse, +-1..5 shifts and single-byte XOR-hex (`_needles`); `redact` withholds the whole text when such a leak has no clean span. Tests: `tests/unit/test_flag_encodings.py` (hypothesis).
- `policy.py`: static AST check of challenge (and solver) source, plus `answer_exposed` (hidden-answer rule, ADR 0006).
- `probes.py`: `junk_inputs` — fixed free stdin values (besides empty) that must not reveal the flag, including a same-class tweak of the first, middle, and last characters, plus one extra index from the match seed; `long_probe` is one `MAX_PAYLOAD_CHARS` (4096) same-class input. Used by the engine's validation probes.
- `events.py`: event types, one typed payload model per type, `SCHEMA_VERSION` (v3; `Event.v` is the minimum reader version; v0-v2 logs still fold), `check_version`, `typed`, `payload()` validation, `apply`/`fold` (ADR 0004). `attack_started` (key, try_no) is emitted before each attack call for presentation; its handler changes no state, so logs written before it existed replay identically. `call_charged.refused` is present only when true (ADR 0016); older logs omit it. `challenge_timeout` (challenge_id, attacker, key, count, voided) is emitted when an attack sandbox run hits the wall or a signal; the try is refunded, and `voided` overwrites Validation to invalid (too slow) so the challenge scores 0 for both sides (`scoring.classic` skips the invalid penalty for `ATTACK_TIMEOUT`). `AttackAttempt.timeout` is present only when true.
- `modes.py`: `MODES` presets (plain `Rules`: classic, quick, gated, checked, efficiency, capped, blitz, ledger, ledger_deep). Every scored preset (scoring kind other than `classic`) carries a token clock (#67, enforced by `test_scored_clock.py`), so latency never decides a result; `match_deadline_s` is only a failing backstop. `config.load_settings` applies `[rules] mode` / `DUEL_MODE` first, then the config's own fields.
- `variety.py`: check-form variety (#79): seeded per-challenge `theme`, the author's `past_designs` in the build prompt, `repeat_reason` rejects a reused title or source. On via `rules.variety` (preset `checked`).
- `solvability.py`: check-form solvability band (design rec R1): `counted` wraps the solver so the arena counts `check()` calls behind a per-try `nonce`; `samples`/`density_program` measure the share of seeded random inputs `check()` accepts. Limits in `rules.solvability` (on in preset `checked`); counts are logged on `challenge_validated`.
- `contract.py`: the `check` challenge form (`compose`, `WRAPPER`, attack-time `with_feedback`, `solver_program`; ADR 0010). the wrapper writes FLAG through `sys.stdout.write` (never `print`), and `compose` rejects any rebinding of `print` or `check` (assignments, defs, classes, imports, args, `global`, decorators on `check`).
- `findings.py`: tamper detector (`scan_build`, `scan_payload`); logged as `finding_flagged`, never scored (ADR 0008). `policy.reason_code` gives rejection reasons a machine code.
- `models.py` handicaps (#38): `AgentSpec.handicap` (`attempts_delta`, `token_budget_mult`, `bank_mult`, `score_offset`) is pinned with the agents in `match_created`; the engine reads per-agent limits through `MatchState.max_attempts(name)` / `attack_token_budget(name)` and `allowance.clock_left` scales the bank. `score_offset` never enters `scores` (replay stays exact); `final_scores()` adds it and decides `leader`/`result`.
- `ghosts.py`: Deep layer phase 1, Ghost Codex (`Rules.deep`, `DeepRule(ghosts, max_ghost_runs=24)`, preset `ledger_deep`; needs ledger; design-deep-layer.md). Each live capture's winning payload becomes a ghost (`ghosts_before`); `ghost_schedule` is a pure seeded order of (ghost, opponent challenge) pairs cut at `max_ghost_runs`. The arena replays them before the terrain draw and allocation (hits are public in the allocate prompt and must be staked 0), $0 API, one `ghost_run{round, ghost_id, target, hit, stdout_sha}` each; a hit records the attack with `ghost` set, 0 attempts, 0 tokens and stake 0; the scorer raises `tampered` for a ghost capture with no matching `ghost_run` hit (or deep off) or a nonzero stake and pays `ghost_award` = max(1, full // 4). Ghost captures breed no ghosts.
- `moments.py`: Deep layer moment detector, pure over events: `moments(events)` / `moment_of(event)`; phase 1 emits `GHOST_STRIKE` exactly for `ghost_run` hits. Moments carry ids only, never payloads or flags. The arena shows a GHOSTS row (`ghost_row`) when ghosts are on.
- `stakes.py`: Sealed Ledger stakes (preset `ledger`; `Rules.ledger`, `LedgerRule` lives in models.py; the arena logs `stakes_set` per attacker per round, before attacks; design-core-logic.md; positional, index i = the opponent's i-th challenge of the round by sorted id): `LedgerRule`, `settle_stakes` (0 or >= `min_alloc`, sum <= `attack_tokens`, else `even_split` and the arena logs `alloc_fallback`). `ledger` scorer: stake 0 = defended; a capture loses `floor(full * min(used, stake) / (2 * stake))`, so 0-50%, never below 1; a capture on a 0 or missing stake raises (tampered). Each staked capture's points (`capture_points`, built on `_captures`, #199) are logged in `round_scored.points` and replay recomputes them; logs from before #199 have no `points` and skip that check. Ties: fewer recorded dollars, then fewer tokens (`series.game_winner`). Keystone (`LedgerRule.keystone`, step 3a): the allocate call also picks one own challenge; the arena logs `keystone_sealed` (sha256 commit of index+seed-derived salt) with the stakes and `keystone_revealed` after the round's attacks, before scoring; a reveal that misses its commit raises (tampered). Defended keystone pays defense again; captured costs the author `solve_award // 2`; an invalid or bad pick forfeits. The pick is never in the opponent's prompts before its reveal; the picker's own allocate prompt shows its sources, and revealed keystones appear in later rounds' memory.
- `terrain.py`: Sealed Ledger seeded terrain (`LedgerRule.terrain`, step 3b): one public stdin transform per valid challenge (identity, reverse, rot13, ASCII swapcase, ASCII xor, b64, prefix), drawn from sha256(seed, round, "<author>:<index>") and logged as `terrain_drawn` before allocation. The arena runs `apply(t, payload)` as stdin; every transform has an exact inverse, and a draw with no inverse for the reference payload falls back to identity. Prompts show `[terrain=<t>]` and a plain description.
- `heat.py`: Sealed Ledger novelty heat (`LedgerRule.heat_window`/`heat_threshold_pct`/`heat_max_pct`, step 3c): similarity `100*LCS//max(len)` of AST walks against the *valid* challenges of the last `heat_window` rounds (the author's own, and when `LedgerRule.heat_vs_opponent` — on in the ledger preset; config load pins a bool via `modes.pin_opponent_heat`, the mode preset's value, else off — the opponent's, filtered before the ref cap; unset in older logs, where `heat.vs_opponent` reads `heat_refs` and replay retries the #238 reading) plus `match_created.heat_refs[author]` (`history_refs`: valid sources the same provider+model built in its last `heat_history_matches` matches in this store, default 3, frozen at creation by `session.open_match`, omitted when empty, at most `heat_ref_cap` newest, none over the parse ceiling or the work-budget walk). v2 heat-on logs require `heat_compare=full`, an explicit `heat_vs_opponent`, `heat_ref_cap`, `heat_metric=lcs-v1` and `heat_history_matches`, and omit `heat_token_cap`; v1 logs that carry `heat_token_cap` still replay. A defended heated challenge keeps its full defense award; a separate `heat_penalty` line (ADR 0006 addendum, capped at `heat_max_pct`% of that award) is charged to the author and logged in `round_scored.heat`, which replay recomputes. `HeatScorer` holds the only state (bounded walk cache, bounded round memo, LCS work count); the engine, replay and arena each own one, and tests inject a fixed `pair` similarity through it. Challenges with a reference not compared exactly are logged in `round_scored.heat_unchecked`, charged 0, never charged on a bound, and shown via `heat_label` as `heat over budget` / `>=N% (heat over budget)`. `match_created.python` records the parsing interpreter. Disclosed in the forge prompt (`agents.heat_rule`) and in memory.
- `heat_tokens.py`: the heat walk (pre-order AST: node types, constant value types, operator names; names and literals dropped) and host limits (`PARSE_BYTES` 65536, `TOKEN_CAP` 256, `REF_CAP` 48). Pure, no cache. Every source under `PARSE_BYTES` keeps its full walk. A source over `PARSE_BYTES` is not parsed; a parser rejection (deep nesting too) walks to nothing.
- `heat_bound.py`: `regime(rule)` (`legacy` no pins / `prefix` both caps / `full` `heat_compare=full`; `LedgerRule` validation refuses a partial, mistyped or out-of-range pin), `pin_heat_bound` (config only: fills `full`, `heat_ref_cap`, `heat_metric=lcs-v1` and `heat_history_matches`, and drops `heat_token_cap`), and `compare`, the one pair path: copied body in linear time, then the exact bit-parallel `lcs` inside the call's `WORK_BUDGET` (`work(a, b)` word ops), then legacy raises `HeatBoundError` (replay: `heat legacy-unreplayable`) and full returns a `heat over budget` `Hot` that is charged 0. The multiset ceiling is only a cold-skip filter. Whole-source admission is capped so every pair the rules can admit fits `WORK_BUDGET` (`admit` / `Rules.max_source_bytes`, and never past `PARSE_BYTES`); `heavy` refuses a denser walk.
- `scoring.py`: `score_round` builds `RoundFacts` and dispatches to `SCORERS[rules.scoring.kind]` (`classic`, `efficiency`, `timed`; `ledger`, stakes wired into matches by #192; ADR 0007); `solve_award`/`defense_award` are the shared base new scorers compose; `add_scores` (deterministic, replay depends on it). Every scorer must pass `TestScorerInvariants`. A defense of a `probe_solved` challenge (difficulty gate in `gate_mode="score"`, #78) pays half. `match_stats` gives valid/capture rates for run reports. `efficiency` (#35): classic, but each capture loses `floor(max_penalty * tokens_used / reference_tokens)` points (never below 1); defenses unchanged, so defense >= capture still holds. `unit="usd"` scores the attack's recorded `usd_micros` (charged at call time and stored on each `AttackAttempt`, so later price changes never alter a replay) rescaled by `reference_tokens / reference_usd_micros` (`cost_used`). `timed` (#36, mode `blitz`): a capture loses `min(full - 1, floor(max_penalty * min(1, tokens_used / par_tokens)))`; both share `_discounted`.
- `prophecy.py`: Prophecy menu tier (design-deep-layer.md Layer 1): 12 `TEMPLATES` of up to 3 atoms over a target's `RoundArtifacts`, `commit`/`verify` (sha256 of canonical JSON + salt), `pick` (invalid reply -> None, logged `prophecy_skipped`, never a random pick), `settle` (vacuous template pays 0, points never below 0, per-round cap, match swing <= pool). Not wired into the engine yet.
- `memory.py`: between-round memory (#19): a pure, bounded, flag-free summary of past rounds built from event-sourced state (own outcomes, opponent challenges and tendencies, scoreboard); never `solver` or `reference_payload`. Kind `summary+scratchpad` (#34) adds the agent's own last note: replies may carry an optional `"notes"` (<= 500 chars), recorded as `note_recorded{agent, round, text}` after redaction against every flag of the match, folded into `MatchState.notes`, and shown only to its author.
- `series.py`: best-of-N (#38), layered above matches: `SeriesRule(games odd, series_max_usd)`, `SeriesState` folded from `series_created`/`game_finished`; `game_seed` = sha256(series seed, game), `game_agents` alternates sides, `game_winner` goes through `decide()` (ledger: fewer dollars then tokens; else fewer attack tokens); a game still tied goes to a sudden-death 1-round match (`SeriesRule.sudden_death`, default on; `Game.sudden_death` names it) and is drawn only if that ties too; done at ceil(N/2) wins or N games.
- `driver.py`: `fold_created` — shared header for series/tournament folds (created-event check + typed state).
- `public.py`: `public_data(event)`, the per-kind allowlist of event fields `duel sync` may store. Unknown kinds keep nothing; source, payloads, solver output, notes and excerpts are dropped at any depth; kept strings go through `public_text` (a scrubbed single token, else `<text omitted>`; titles are dropped). Add a field here only if it is safe to publish.
- `results.py`: frozen row dataclasses (`MatchProjection`, `Stored`, `RunCounts`, ...) passed between `app/sync.py` and any `ResultsStore`.
- `ratings.py`: `duel ratings` (#39), offline over every completed match log (`FileEventLog.ids()` + `events.fold`): one `Result` per match between distinct entrants (`provider:model`, fakes add `@skill<n>`), decided on raw `scores` by `raw_winner` (handicap `score_offset` never counts; a handicapped agent is its own entrant `...+hc(...)`). `duel ratings` skips unreadable logs with a warning and a stderr count instead of aborting. Elo (K=32, from 1500) folds in `match_id` order; Bradley-Terry (MM, draws = half wins, one virtual draw vs a 1500 anchor) is order-independent and reported with seeded bootstrap 95% CIs. Bootstrap CIs use only the resamples that include the entrant (#138).
- `tournament.py`: tournaments (#39): `TournamentRule` (`[tournament] entrants`, >= 3; `format: Literal["auto", "round_robin", "swiss"]`, `kind() -> Kind`; `auto` = round robin up to 6, else Swiss for ceil(log2 n) rounds; each pairing a `SeriesRule` series), `round_robin` (circle method, one bye each when odd), `swiss_round` (pairs down the standings, backtracks to avoid rematches, bye to the lowest without one), standings 1 / 0.5 / bye 1, ties by `sha256(seed:name)`; folded from `tournament_created`/`pairing_finished`/`pool_scored`. Opt-in shared pool (`pool = true`): `DecayRule` + `decay_value` are CTFd's `linear`/`logarithmic` dynamic value (first solve = `initial`, every solver gets the value at the final solve count, floored at `minimum`); `pool_points` breaks ties on series points. `pool` is a reserved entrant name.
- `errors.py`: `DuelError` hierarchy; CLI maps any `DuelError` to exit 2.

Gotchas
- Value models are frozen with `extra="forbid"`; adding a field to `MatchState` breaks loading old state files unless it has a default.
- Changing scoring changes replay results for old matches; replay folds the event log (`events.fold`), recomputes each `round_scored` delta and diffs the folded state against the snapshot. `events.py` holds the event types and `apply`, the only place match state changes; add a handler there for any new event type.
- Loosening `policy.py` widens what runs in the sandbox; needs a security review.
